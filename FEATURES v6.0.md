# ALTAURI FEATURES v6.0 OVERVIEW

Документ описывает функциональные возможности системы ALTAURI на текущий момент.

---

## 1. Редактор Схем (Schematic Editor)

### Управление Узлами (Nodes)

* **Создание:** Добавление новых Атомов на сцену через контекстное меню (Right Click). Автоматическая генерация ID.
* **Перемещение:** Drag & Drop узлов. Автоматическая перерисовка проводов в реальном времени.
* **Удаление:** Удаление узла с автоматическим удалением всех подключенных к нему проводов.
* **Свойства:** Кнопка "Настройки" (шестеренка) на узле открывает окно свойств (`Properties Window`). Окно можно перетаскивать.

### Управление Связями (Wires)

* **Соединение:** Перетаскивание (Drag) от выходного порта (Output) к входному (Input). Автоматическое определение направления потока данных.
* **Визуализация:** Провода отрисовываются плавными кривыми Безье.
* **Удаление:** Связи удаляются при удалении узлов или через Undo.

### Навигация и Вид

* **Переключение режимов:** Кнопка `Toggle View [F5]` переключает между режимом редактирования (Editor) и режимом устройства (Device).
* **Сброс:** Кнопка `Reset [R]` полностью очищает текущую схему и память.

## 2. Система Истории (Undo / Redo System)

Полноценная система отмены и повторения действий, построенная на паттерне **Command**.

* **Поддерживаемые действия:**
  * Создание/Удаление Атомов.
  * Соединение/Разъединение контактов.
  * Перемещение Атомов.
* **Горячие клавиши:**`Ctrl+Z` (Undo), `Ctrl+Y` (Redo).
* **Отказоустойчивость:** Ошибки внутри команд не ломают историю и не вызывают краш приложения.

---

## 3. Сохранение и Загрузка (Persistence)

* **Формат файла:**`.altauri` (структура JSON).
* **Сохранение:** Файл -> Save Project. Сохраняет структуру графа, типы атомов, координаты позиций и связи.
* **Загрузка:** Файл -> Load Project. Полное восстановление состояния сцены из файла, включая позиции узлов.
* **Безопасность:** Система устойчива к отсутствию данных или неверным типам в JSON файле.

---

## 4. Архитектура "Под Капотом" (Under the Hood)

### Управление Данными (Core Logic)

* **Signal Propagation:** Автоматическое распространение значений по графу. Если изменился выход Атома, все подключенные входы обновятся.
* **Priority Queue (Scheduler):** Система очередей с приоритетами предотвращает переполнение стека (Stack Overflow) и зависание UI при сложных вычислениях.
  * `CRITICAL`: Ввод пользователя.
  * `NORMAL`: Логика.
  * `BACKGROUND`: Обновление UI/Логи.
* **Reactive Contacts:** Контакты (`Contact`) поддерживают механизм подписки (`Subscribe`). Любой элемент UI может следить за изменением данных.

### Управление Памятью (Memory Safety)

* **IDisposable:** Все сущности (Атомы, Виды, Драйверы) реализуют интерфейс `dispose()`.
* **Clean Up:** При удалении элементов гарантированно удаляются слушатели событий и ссылки, предотвращая утечки памяти.

### Событийная Модель (Event Bus)

* **Impulsys:** Глобальная шина событий. Позволяет компонентам общаться без прямых ссылок друг на друга.
  * Примеры событий: `REDRAW_WIRES`, `ATOM_DELETED`, `PROPERTIES_REQUEST`.

---

## 5. Расширяемость (Extensibility)

* **Atom Definitions:** Новые типы атомов добавляются через реестр (`AtomDefinitions.reg`). Не требует изменения ядра системы.
* **Drivers:** Активные атомы (таймеры, датчики) реализуют интерфейс `Driver` и автоматически подключаются к главному циклу обновления.
