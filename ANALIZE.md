# ALTAURI: Анализ Потенциала

---

## 🧬 Что это такое на самом деле?

ALTAURI — это **визуальная среда моделирования систем** на основе dataflow-парадигмы. Ты построил не просто "редактор схем", а **фундаментальную платформу** для создания визуальных языков программирования.

Архитектурно это близко к:

* **Unreal Blueprints** — визуальное программирование логики
* **Max/MSP / Pure Data** — audio/visual patching
* **Node-RED** — IoT и автоматизация
* **Unreal Material Editor** — shader graphs
* **vvvv / TouchDesigner** — creative coding

Но у ALTAURI есть **уникальные черты**:

| Особенность                             | Значение                                                                                                               |
| -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **Иерархические сборки**  | Можно "провалиться" внутрь любого узла — это как функции в функциях     |
| **Активные атомы**              | Узлы могут быть живыми (FPS Monitor, датчики) — сами генерируют данные          |
| **Signal Queue с приоритетами** | Защита от бесконечных циклов, предсказуемое поведение                           |
| **Event Bus (Impulsys)**                     | Полная развязка компонентов — UI не знает о логике, логика не знает о UI |
| **Кроссплатформенность** | HTML5, Desktop, потенциально mobile                                                                                |

## 💎 Почему ALTAURI особенный?

### 1. **Архитектура "всё есть атом"**

Всё — от простого NAND до сложной нейросети — это **атом**. Это даёт:

* Единообразие API
* Неограниченную композицию
* Переиспользование на любом уровне

### 2. **Иерархия без ограничений**

Большинство node-редакторов — плоские. В ALTAURI:

text

Game

└─ Enemy AI (Assembly)

```
   └─ Pathfinding (Assembly)

        └─ A\* Algorithm (Assembly)

             └─ Priority Queue (Assembly)

                  └─ Basic atoms...
```

### 3. **Active Atoms — живые узлы**

Обычно узлы — пассивные функции. В ALTAURI:

haxe

**class**HeartbeatAtom**extends**Atom {

**// Этот атом "дышит" сам по себе**

**override**function**\_onUpdate**(**dt**) {

**\_outputs**[**0**].**value** = **Math**.**sin**(**time**);

```
}
```

}

### 4. **Signal Queue — защита от хаоса**

Priority-based очередь защищает от:

* Бесконечных циклов
* Stack overflow
* Зависания UI

### 5. **Event Bus — чистая архитектура**

UI ↔ Логика полностью развязаны:

text

[NodeView] --Impulse--> [NodeEditor] --Impulse--> [Assembly]

```
 ↑                                                     |

 └─────────────── Impulse ─────────────────────────────┘
```
