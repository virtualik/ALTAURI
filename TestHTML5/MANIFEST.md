# ALTAURI v3 :: MASTER MANIFEST (v1.2)

## 1. Архитектурные Слои (Layers)

Проект разделен на 4 основные грани взаимодействия:

1. **IO (Core / Binary-CPU):** Слой чистой логики. Headless. Сервер, роутеры.
2. **ED (Editor):** Слой разработчика. Визуализация графа, Drag & Drop, создание схем.
3. **GO (Device / Graphic Output):** Слой пользователя. HMI (Интерфейс), приборные панели.
4. **CL (CLI):** Командный интерфейс. Текстовое управление (планируется).

---

## 2. Ядро (Core / IO Layer) — Реализовано

* **Contact:** Первичная частица данных. `Direct Link`, `Subscribe`, `Dynamic`.
* **Atom:** Функциональный узел.
* **Assembly:** "Черный ящик" (контейнер графа).
* **Blueprint:** ДНК схемы (JSON).
* **AtomDefinitions:** Библиотека чертежей.
* **AssemblyFactory:** Строитель экземпляров.
* **Serializer:** Сохранение/Загрузка JSON.
* **Impulsys + Impulse:** Шина системных событий (Event Bus).
* **Utils:** Защита от переполнения стека.

---

## 3. Редактор (Editor / ED Layer) — Реализовано

* **NodeEditor:** Менеджер сцены. Управление узлами и связями.
* **NodeView:** Визуальное представление Атома. Drag & Drop.
* **WireLayer:** Холст для постоянных проводов (Кривые Безье).
* **ContextMenu:** Контекстное меню (Правый клик -> Добавить Атом). Поддержка `Esc` и клика мимо для закрытия.
* **Visual Wiring:** Рисование связей мышью (Drag & Drop проводов). Автоматическое обновление Blueprint и Runtime.

---

## 4. Интерфейс Устройства (UI / GO Layer) — Реализовано

* **DevicePanel:** Автогенератор интерфейсов.
* **HMIWidget:** Базовый интерфейс виджета.
* **NumberInput / NumberDisplay:** Виджеты ввода/вывода чисел.

---

## 5. Ключевые паттерны (Core Patterns)

1. **Direct Subscription:** Прямая передача значений.
2. **Event Bus (Impulsys):** Децентрализованная система оповещений.
3. **Cascade Mutation:** Каскадное обновление данных.
4. **Data Driven:** Логика отделима от кода через Blueprint.
5. **Loop Protection:** Защита от Stack Overflow.

---

## 6. Roadmap (План развития)

### Этап 1: Совершенствование UX (Editor Tweaks)

* **Ghost Wire Bezier:** Реализовать отрисовку "воздушного" провода (при перетаскивании) с использованием кривых Безье (как у постоянных проводов), вместо прямой линии.

### Этап 2: Библиотека Базовых Интерактивных Атомов (Refactoring)

Реорганизация `AtomDefinitions`. Удаление абстрактных тестовых заглушек. Внедрение базового набора для визуального программирования:

1. **Pin (Пин):**
   * *Визуал:* Круглая форма.
   * *Функция:* Интерактивный вход/выход. Позволяет задавать значение вручную или просто как точка соединения.
2. **Button (Кнопка):**
   * *Визуал:* Прямоугольная кнопка.
   * *Выход:*`true` при нажатии (MouseDown), `false` при отпускании (MouseUp).
   * *Интерактивность:* Реагирует на мышь в режиме Editor и Device.
3. **LED (Индикатор):**
   * *Визуал:* Круг или квадрат.
   * *Вход:* Boolean.
   * *Логика:* Светится зеленым при `true`, серым/черным при `false`.

### Этап 3: Файловая система

* **Save/Load:** Сохранение текущей схемы в файл и загрузка из файла.

### Этап 4: Развитие Core

* **Pulse Engine:** Планировщик (разрыв рекурсии).
* **CLI Interface:** Текстовый пульт.
